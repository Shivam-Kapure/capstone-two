## 4. Known limitations

- **Tunnel URL is temporary.** On Windows with the Docker driver, NodePorts are not published to the host, so
  `http://localhost:30199` does not work (verified: curl exit 7). `minikube service --url` opens an SSH tunnel on a random
  `127.0.0.1` port that changes each run and only lives while that terminal stays open.
- **In-memory data.** Payments and notifications live in each backend process. They reset on restart, and the two
  Kubernetes replicas hold different data; `sessionAffinity: ClientIP` keeps one client on one pod, but it is not shared state.
- **Deploy Cluster stage only echoes.** Jenkins does not apply manifests; deployment was done with `kubectl apply` by hand.
- **Ansible from WSL** reaches the Compose port (Docker Desktop forwards it) but not the Windows-only Minikube tunnel or node IP.
- **Demo only.** No real payment processing, no auth, no persistence.
